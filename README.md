# pgilstru

Personal docs site (Jekyll, Just the Docs theme), plus two CCDC tools:

- **Taddle** (incident report builder) at `/taddle/`
- **Kudos** (inject builder) at `/kudos/`

Published with GitHub Pages. To run it locally (Ruby 3.2+):

```bash
bundle install
bundle exec jekyll serve
```

Both tools are plain static pages, so you can also just open their `index.html` files in a browser.
